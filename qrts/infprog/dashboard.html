Load an image

Pick any photo. It is letterboxed to 640×640 (aspect preserved, grey 114 padding, the same as ultralytics), quantised to INT8 CHW, and becomes the frame the accelerator reads. A matching RGB888 copy is kept alongside it so detections are drawn on the picture rather than on the quantised tensor.

JPEG, PNG, BMP, GIF, WEBP. Conversion happens on this PC.

This is exactly what is written to SDRAM, letterbox bars and all.

Model & frame transfer

Streams a file into SDRAM. JTAG manages about 4,900 words/s — roughly two minutes for the 2.46 MB model — and needs nothing but the USB-Blaster. Ethernet does the same in seconds once the link is in MII; check the Ethernet panel before choosing it.

There is no flow control in this protocol — the FPGA drops what it cannot absorb. Start with gap 0; if verify reports dropped words, raise it.
must be exported for ARRAY_SIZE 16; the IDENT register reports what the bitstream expects

What the board's LEDs mean

Bus activity is nanoseconds wide, so every indicator is stretched to about 1/12 s — otherwise nothing would ever appear to leave its idle state. At rest you should see one blinking green (heartbeat) and one steady green (reset released); everything else dark.
